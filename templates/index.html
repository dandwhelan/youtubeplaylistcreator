🔑 API keys & credentials

Required to create playlists. It is a free key file from Google that lets this app add playlists to your own account. One-time setup, about 5 minutes. Sign in to Google with the account you use for YouTube Music, then:

  1. Create a Google Cloud project (any name, e.g. "Playlist Bot").
  2. Enable "YouTube Data API v3" for that project.
  3. Set up the OAuth consent screen: any app name, your own email, audience External.
  4. Add yourself as a test user (your YouTube Google email). Without this Google blocks the sign-in.
  5. Create an OAuth client, application type Desktop app, and click Download JSON straight away (Google only offers the file when the client is created).
  6. Upload that client_secret….json file below, then click Connect YouTube at the top right and approve the sign-in. Google shows "Google hasn't verified this app": click Advanced, then Go to … (unsafe). That is normal for a personal app.

If a link opens the wrong project, pick yours in the project menu at the top of the Google page. Full walkthrough: README, Steps 1 to 4.
