❓ How this works (start here if you're new)

The 3 steps

  1. Connect where the playlist goes: YouTube Music, Spotify, or both. Setup steps are in API keys & credentials below. You only do this once.
  2. Add your bands: type them, upload a text file, or photograph a festival poster.
  3. Pick a mode (what kind of songs), choose Save to, and click Create playlist.

Which YouTube sign-in should I use?

  • YouTube Music sign-in (recommended): you copy some text from your browser once. No daily limit and no Google account setup.
  • Google key file: the official method, but Google only allows about 199 songs per day. Longer runs pause and continue the next day.

What is the "quota"?

Google limits how many songs an app can add per day with the official method. The Quota badge at the top shows roughly how many adds are left today. It resets at midnight US Pacific time (8am UK). With the YouTube Music sign-in or Spotify, you can ignore it.

What if it stops halfway?

Progress is saved after every song. If the quota runs out, the internet drops, a sign-in expires, or you close the app, a yellow Resume banner appears next time. Click it to carry on from the same band with no duplicates. If a sign-in expired, reconnect first.

How does Spotify work here?

Choose Save to → Spotify. By default, songs are picked straight from Spotify's own data (ranked by Spotify popularity). Alternatively, pick them with YouTube Music's data (ranked by views); each one is then looked up on Spotify by band and song title. With that option, a few songs may have no Spotify match (e.g. YouTube-only live videos). The app skips those and tries the band's next song instead. Spotify requires a Premium account for this.

Other terms

  • Dry run: a preview. Shows which songs would be added without creating anything.
  • Privacy: Private = only you; Unlisted = anyone with the link (YouTube only; on Spotify it's the same as private); Public = shows on your profile.
  • Genre Cluster: sorts your bands into Metal / Rock / Punk / Electronic / Pop and makes one playlist per group.
  • Setlist Mode: uses songs the band actually played live recently (needs a free setlist.fm key).
  • Festival poster: reads band names from a poster picture using Google's Gemini AI (needs a free Gemini key). Check the list it produces, because it can misread names.

This is Google's official method: a free key file that lets this app add playlists to your own account, limited to about 199 songs per day. One-time setup, about 5 minutes. Sign in to Google with the account you use for YouTube Music, then:

  1. Create a Google Cloud project (any name, e.g. "Playlist Bot").
  2. Enable "YouTube Data API v3" for that project.
  3. Set up the OAuth consent screen: any app name, your own email, audience External.
  4. Add yourself as a test user (your YouTube Google email). Without this Google blocks the sign-in.
  5. Create an OAuth client, application type Desktop app, and click Download JSON straight away (Google only offers the file when the client is created).
  6. Upload that client_secret….json file below, then click Connect YouTube at the top right and approve the sign-in. Google shows "Google hasn't verified this app": click Advanced, then Go to … (unsafe). That is normal for a personal app.

If a link opens the wrong project, pick yours in the project menu at the top of the Google page. Full walkthrough: README, Steps 1 to 4.

The Google key above is limited to about 199 track adds per day. Signing in with your browser's YouTube Music session instead writes playlists with no daily limit. When set, it is used automatically.

  1. On a computer, open music.youtube.com in Chrome, Edge or Firefox and make sure you're signed in (your picture is at top right).
  2. Press F12 (Mac: Cmd+Option+I). A panel of developer tools opens. That's normal.
  3. In that panel, click the Network tab. In its small search/filter box, type browse.
  4. On the YouTube Music page, click Library (left side). A line starting with browse appears in the panel. If several do, any of them works.
  5. Right-click that line → Copy → Copy request headers (Firefox: Copy Value → Copy Request Headers).
  6. Click in the box below, paste (Ctrl+V / Cmd+V), then click Save sign-in. You can close the developer panel (F12 again).

⚠️ This text works like a password for your YouTube account. It stays on this computer in browser.json, so don't share it. It stops working if you sign out of YouTube in that browser; just repeat these steps.

Spotify needs a free "developer app" so this tool can create playlists on your account. You need Spotify Premium, because Spotify blocks this for free accounts. One-time, about 3 minutes:

  1. Go to the Spotify Developer Dashboard and log in with your normal Spotify account. Accept the terms if asked.
  2. Click Create app. Use any name and description (e.g. "Playlist Creator").
  3. Under Redirect URIs, paste this and click Add:
    http://127.0.0.1:5000/spotify/callback
    (also add http://127.0.0.1:8888/callback if you'll use the command-line version). It must be 127.0.0.1; Spotify rejects localhost.
  4. Under "Which API/SDKs are you planning to use?", tick Web API. Agree and Save.
  5. Open the app's Settings, copy the Client ID (you don't need the secret), paste it below and click Save keys.
  6. Click Connect Spotify and approve.
